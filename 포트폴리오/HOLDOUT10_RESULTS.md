# 홀드아웃 10건 End-to-End 실측 (배선된 엔진)

> 검증 방식: 국회 의안정보시스템 Open API로 **개발에 전혀 쓰지 않은 새 의안**을
> 다운로드 → 배선된 프로덕션 파이프라인(`tag_pipeline.run_pipeline`, 증원
> 라우팅·유추 추정·신뢰도 라벨 포함)으로 실행 → NABO 공식 비용추계서와 대조.
> LLM 파싱은 신뢰 LLM(Claude)이 수동 대행(프로덕션 solar 비결정성 회피).
>
> **신뢰도 라벨**은 정답을 보지 않고 결정한다 — 전제값을 조문/DB에서 채웠는지,
> 분포가 수렴하는지로 판정. "오차 자체"는 처음 보는 의안이라 알 수 없지만,
> "오차가 클 조건"(조문 밖 전제가 곱해지는지 등)은 정답 없이 판단 가능하다.

## 케이스별 상세 (면접 설명용)

### 1. 2207404 공무원보수위원회 — 회의수당형
- **무엇:** 27명 위원회 신설, 민간위원 회의참석수당
- **산식:** `(정원 - 당연직) × 회의수당단가 × 회의횟수` (NABO와 동일 구조)
- **신뢰도가 🟡저신뢰인 이유(정답 없이 판정):** 회의횟수가 조문에 없어 폴백값(연 4회,
  DB 최빈값)을 썼고, 단가도 표준관행값(25만→실제 파서 20만)을 썼다. 조문 밖 전제
  2개가 곱해지므로 저신뢰로 라벨. → 실제 오차 +20%, 라벨과 방향 일치.
- **의미:** NABO 관용 오차 범위. 정답도 현행 훈령값(35만·3회)을 "가정"으로 씀.

### 2. 2211768 원자력안전위원회 상임위원 증원 — 인건비증원형 ⭐
- **무엇:** 상임위원 2명→5명(+3), 사무처장 겸직 배제(별도 1명)
- **문제였던 것:** 개정형("상임위원을 5명으로 늘림")은 위원회 "신설" 트리거가 없어
  `group_committee_articles`가 개체를 0개로 잡아 **원래 무출력(계산 시작조차 안 됨)**.
- **해결(라우팅 추가):** `committee_increment_gate` — 규칙으로 "N→M 증원" + "겸직 배제
  = 인원 +1"(일반 원리)을 탐지, `calculate_member_increment`로 `증원수 × 정무직급여
  × (1+기관부담+기본경비)` 계산. 규칙이 못 잡는 문구는 LLM 백업.
- **신뢰도 🟢확정:** 증원수(조문 명시)·급여(공식 봉급표)가 모두 확정 소스.
- **결과: 오차 +3%** (규칙 게이트가 LLM 없이 자동 탐지). 무출력 → +3%로 개선.
- **일반화 검증:** "겸직 배제 +1"은 이 의안 맞춤이 아니라 모든 겸직배제 조문에
  적용되는 규칙. 회귀 테스트 44건 0 변경(오탐 없음) 확인.

### 3. 2210547 국민권익위 검찰고충민원 처리 과(課) 신설 — 일반직 정원증원
- **무엇:** 1개 과(정원 12명) 신설 → 일반직 인건비
- **산식:** `증원 정원 × 급여 × (1+기관부담+기본경비)`
- **핵심 개선(일반화):** 처음엔 일반직을 "5급 15호봉"으로 임의 근사 → 정답 인건비
  대비 -34%. 특정 직급 가정은 오버핏이라, **"직급 미상 시 인사혁신처 고시
  '전체공무원 평균 기준소득월액'(7,140만원)을 쓴다"**는 일반 규칙으로 교체.
  → 인건비 오차 **-34% → +1%**. 문서화된 공식 통계라 방어 가능.
- **신뢰도 🟡저신뢰:** 실제 직급 구성(과장급 포함)을 모르므로 저신뢰로 라벨.
- **결과:** 인건비 +1% / 총액 -16%(자산취득비 등 별도 라인아이템은 미산정).

### 4. 2200815 금융위 금융보안전문위원회 신설 — 상임위원 신설(정무직) ⭐ 최고정확
